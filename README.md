# Vision Screening Data Model — Sample ERD

Sample entity-relationship model authored by **Edgent LLC** (SDVOSB, Bastrop TX) illustrating our data-modeling
approach for a statewide K-12 vision screening data collection platform: student record continuity across LEA
enrollments, DSHS-aligned screening workflow (OD/OS acuity, exceptions), SB 12 consent tracking, referral and
follow-up lifecycle, campus-to-LEA certification, and full auditability.

- `erd.md` — the entity-relationship diagram (Mermaid) with design notes
- `schema.sql` — illustrative PostgreSQL DDL for the core entities

This is a **sample** for evaluation purposes; it is not the production schema of any Edgent system.
